Detailed Description

A continuous-time first-order Low Pass Filter (LPF) utilizing microsecond elapsed time.

Lpf provides first-order low-pass filtering suitable for smoothing noisy sensor data (e.g. ADC readings, temperature, gyro/accelerometer, or speed). Unlike simple discrete filters with a fixed sampling period, Lpf dynamically measures the actual elapsed time between consecutive calls via ElapsedTime. This allows accurate and stable filtering even when the sampling interval is non-uniform or jittered.

Filter Equation

\[y(t) = y(t - \Delta t) - (y(t - \Delta t) - x(t)) \cdot \text{ratio} \cdot \Delta t \]

where:

  • \( x(t) \) is the new raw input value.
  • \( y(t) \) is the filtered output.
  • \( \Delta t \) is the elapsed time in seconds since the previous update.
  • \( \text{ratio} \) is the filter convergence rate coefficient.

Example Usage

#include <Lpf.h>
Lpf filter(5.0f); // Ratio = 5.0
void loop(void)
{
float rawAdc = readAdc();
float filteredValue = filter.calculate(rawAdc);
// Use filteredValue...
}

float Lpf::calculate ( float value)

Updates the filter state with a new raw input value and returns the filtered output.

Measures the elapsed time since the previous call, calculates the new filtered value using first-order low-pass filter equation, and resets the internal timer.

Parameters
[in]valueRaw input sample to be filtered.
Returns
The updated filtered value.

Calculates the next filtered output sample given the raw input value. The method obtains the microsecond elapsed time since the previous calculation, resets the timer, and computes the 1st-order discrete approximation: \( mData = mData - (mData - value) \times mRatio \times \Delta t \).

void Lpf::setCurrentData ( float data)

Manually sets the current filtered value.

Useful for initializing the filter state to the first measured sample to prevent an initial ramp-up delay or transient offset.

Parameters
[in]dataThe initial or forced value to set.

Overwrites the current internal filtered state with the specified value. This can be used to set an initial baseline (e.g., initial sensor reading) to avoid startup transient lag.
